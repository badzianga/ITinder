# Tinder Backend - Python + Flask

## Jak uruchomić
Otworzyć folder backend w PyCharm, coś poklikać i może się załaduje venv (virtual environment).
Powinna być gotowa konfiguracja do uruchomienia serwera.

Jeśli nie zadziała poprzez PyCharm, można poprzez terminal:
- wejść do folderu backend `cd backend`
- stworzyć venv `python -m venv .venv`
- aktywować venv `source .venv/bin/activate`
- zainstalować paczki `pip install -r requirements.txt`
- odpalić serwer `python app.py`
